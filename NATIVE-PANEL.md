# Purge native sidebar edition

The `native-panel` branch of this fork maintains a standalone `dsh-purge-panel` UI plugin. `master` keeps upstream state; the original author is YuJunZhiXue/dsh-purge, and copyright and the license are preserved in the LICENSE files at the repository root and in the UI package.

## Installation and updates

The official `dsh-purge` and `dsh-purge-panel` are two separate packages. The first keeps its original functionality; the second registers the right-side Purge tab, the settings layout, and the styles that hide the old entry points. Updating the official package does not overwrite the standalone UI files. Do not use it together with early versions that embedded the UI directly in `dsh-purge@1.1.71-local.*`.

```sh
cd packages/purge-panel
npm ci --ignore-scripts --legacy-peer-deps
npm run build
npm test
npm pack --ignore-scripts
# Use the CLI from your current DSH install:
dsh plugin --profile desktop add ./dsh-purge-panel-1.1.0.tgz
```

Install and enable the official Purge first, then install the UI package. Open the right sidebar "＋ → Purge". Disabling the UI package restores the official entry points without deleting the original settings.

## Following upstream

```sh
git fetch upstream
git switch native-panel
git merge upstream/master
cd packages/purge-panel
npm ci --ignore-scripts --legacy-peer-deps
npm run build
npm test
```

After merging, check whether the official `/dsh-purge/*` API and the `.dshp-launch`, `.dshp-hero-chip`, and `.dshp-tab-chip` entry selectors have changed. On-device test the new version, then update the compatibility version notices and tests before packing the UI. New official settings do not appear automatically in the standalone UI and require explicit adaptation.

The current compatibility verification baseline is official Purge 1.1.71. Other versions show a compatibility notice; unavailable interfaces show a notice as well. The UI uses the `dshpp-` style prefix and a standalone locale to avoid mixing with upstream styles. No scheduled task or loader patch has modified the official install files.

## Verification

`npm test` verifies native tab registration, draft preservation on category switch, refresh not overwriting input, view pages not auto-saving, old entry hiding rules, and version-change and service-error notices. The migration was verified on DSH Desktop: after the official package restored the original, the right-side standalone UI still loaded and the original prompt file was unchanged.

CI only tests and packs; it does not publish to npm, GitHub Releases, or the plugin market. Any formal distribution is decided separately.

For the source structure and this round's refactoring notes, see the [UI package docs](packages/purge-panel/README.md#110-modularization). `client.js` is generated by `npm run build`; after changing source you must rebuild.
