## Avatar list maintenance

The avatars in the README are generated by `scripts/update-contributors.mjs`, which merges the personal homepage links on this page with the GitHub contributors API and keeps the historical list in `.github/contributors.json`. The original author, upstream committers, and manual acknowledgments are all preserved.

- New analysis or verification contributors: add the personal homepage and the specific contribution to the table above; the list refreshes automatically after merge.
- New code contributors: the daily scheduled job picks up entries from the default branch's GitHub contributors data; GitHub statistics may lag.
- Manual refresh: Actions → **Update contributor avatars** → **Run workflow**; you can also set `GH_TOKEN` locally and run `node scripts/update-contributors.mjs`.
- Offline check: `node scripts/update-contributors.mjs --check`. Do not hand-edit the `CONTRIBUTORS:START/END` block in the README.

The workflow is scheduled daily at 10:23 Beijing time (GitHub scheduling may lag), and it only commits the generated list and README; on API errors or an incomplete list it exits as a failure and does not clear existing acknowledgments. To correct a historical attribution, check both this page and the list snapshot.
